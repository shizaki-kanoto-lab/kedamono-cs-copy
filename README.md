# kedamono-cs-copy

ケダモノオペラのキャラクターシート（CS）をNotionで管理し、Discordに貼れる形式でコピーするためのツールです。

『ケダモノオペラ』（著：池梟リョーマ／新紀元社）のファンが作成した非公式ツールです。公式とは関係ありません。ルールブックの本文は含みません。[公式のガイドライン](https://operarpg.jp/guideline)に沿って公開しています。

不具合・要望・削除のご依頼は、X（[@shizaki_kanoto](https://x.com/shizaki_kanoto)）までお願いします。

- コピー用ページ: https://shizaki-kanoto.is-a.dev/kedamono-cs-copy/
- Notionテンプレート: https://ivory-wednesday-73f.notion.site/CS-4101b663c48f81e6955ded5097afe1ac

## 使い方

1. Notionテンプレートを自分のワークスペースに複製します。
2. 表にキャラクターを追加します。
3. 「📋 コピー」を押します。新しいタブが開き、CSがコピーされます。自動でコピーされないときは、開いたページをクリックしてください。
4. Discordに貼り付けます。

## 出力の形式

````text
```
【ケダモノ名】サンプル
【ケダモノ種】（例）あなたのケダモノ種
【群れ】（例）あなたの群れ
【権能】叡智
（中略）
【伝説】（例）灯台の光を見た者は、帰り道を忘れるという

【設定・メモ】
（例）穏やかで聞き上手。物語の結末にだけは口うるさい。
```
【CS URL】https://example.notion.site/page
````

- 項目は、公式の[ケダモノシート](https://operarpg.jp/kedamono)の順です（ケダモノ名、ケダモノ種、亜種、群れ、権能、欲望、疑似餌の姿、住処、伝説、設定・メモ）。受難ポイント、予言、特技など、プレイ中に変わる欄は出力しません。
- CSはコードブロックで囲みます。
- 空欄の項目は出力しません。
- `【CS URL】` はブロックの外に出力します。未設定のときはNotion標準のURL（`https://www.notion.so/ページID`）を使います。
- コピー用ページの「CS URLを付ける」を外すと、URLなしでコピーし直します。選択はブラウザに保存されます。

## CSのURLを公開URLにする

`【CS URL】` は、設定しなくてもNotion標準のURLで付きます。公開URLにしたいときは、最初に1回設定します。

1. キャラクターのページを1つ、「共有」からWeb公開します。
2. 公開URLをコピーします。
3. 「📋 コピー」を押し、開いたページの「CS URLの設定」に貼って保存します。

設定は使っているブラウザに保存され、サーバーには送信されません。別のブラウザや端末では、もう一度設定してください。Web公開や共有をしていないページは、他の人には開けません。

## テンプレートを使わずに作る

Notionのデータベースに次のプロパティを作ります。名前は表のとおりにしてください。

| プロパティ | 種類 | 備考 |
|---|---|---|
| ケダモノ名 | タイトル | |
| コピー | 数式 | [notion-formula.txt](notion-formula.txt) の内容 |
| ケダモノ種 | テキスト | |
| 亜種 | テキスト | 任意 |
| 群れ | テキスト | |
| 権能 | マルチセレクト | 暴虐、狡猾、慈愛、叡智 |
| 欲望 | テキスト | |
| 疑似餌の姿 | テキスト | |
| 住処 | テキスト | |
| 伝説 | テキスト | |
| 設定・メモ | テキスト | 改行もそのまま出力します |
| 作成日 | 日付 | 出力しない管理用の列 |

## 仕組み

1. 「コピー」列の数式が、CSの内容をURLの `#` 以降に入れたリンクを作ります。
2. リンクを開くと [index.html](index.html) が `#` 以降を読み取り、`【CS URL】` を足して、クリップボードにコピーします。

`#` 以降はサーバーに送信されません。ただし、リンクそのものにCSの内容が含まれるので、リンクを共有すると内容も伝わります。

コピー用ページは、`main` ブランチのルートをGitHub Pagesで配信しています。
